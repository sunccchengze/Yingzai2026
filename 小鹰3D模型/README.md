# 小鹰 · 3D 吉祥物模型（两版横向比较）

> 英仔爱心社吉祥物「小鹰」的两个平行 3D 建模版本，均已归档在本目录下。
> 两版都对齐同一套官方 2D 参考图（`public/images/小鹰/*.png`），但由两条会话分支独立建模，
> **气质、精度、工程配置各有侧重**。本文做横向比较，方便你挑一版定稿 / 继续精修。

## 目录结构

```
小鹰3D模型/
├── README.md                    ← 本文件（索引 + 横向比较）
├── 展翅写实版_小鹰/             ← 版本 A（会话分支 01a085a2）
│   ├── 小鹰_3D.blend            Blender 4.5 工程
│   ├── preview.png              竖版预览（1000×1250）
│   └── README.md                该版细节
└── 高精绒羽版_小鹰/             ← 版本 B（会话分支 01a085bc）
    ├── 小鹰.blend               Blender 4.2 工程
    ├── preview/xiaoying_hero.png  横版预览（1024×768）
    └── README.md                该版细节
```

> 两版的**可复现建模脚本**统一放在仓库 `scripts/` 下（见下表「脚本」行），脚本内的默认输出路径已
> 指向本目录对应子文件夹，重跑脚本即可把成品再生成到此处。

## 横向比较表

| 维度 | 版本 A — 展翅写实版 | 版本 B — 高精绒羽版 |
| --- | --- | --- |
| 来源分支 | `arena/01a085a2-yingzai2026` | `arena/01a085bc-yingzai2026` |
| 造型姿态 | **展翅 / 飞行** | 默认可旋转的飞行姿态（角色根 `XiaoYing_Root`） |
| 质感路线 | **偏写实**：重叠小羽片搭出毛茸茸层次（Sheen + 次表面散射） | **绒羽 / 幼鸟绒毛**：粒子毛发（父/子毛发，可调超密）+ Sheen + SSS |
| 精度 | 脚本盲渲、**未经人工目视精修**（README 自述） | 目标「高精度」，配色从参考图取样 |
| Blender 版本 | 4.5 | 4.2 LTS（或更新） |
| 预览图 | 竖版 `preview.png` 1000×1250（1.40 MB） | 横版 `preview/xiaoying_hero.png` 1024×768（1.04 MB） |
| 相机 | Cycles 场景已就绪：1 组相机 + 灯光 + 台座 | **4 台相机**：`Camera_Hero/Front/Side/ThreeQuarter` |
| 模型结构命名 | `头_大圆脸 / 眼 / 喙_上下 / 体羽_背侧前胸 / 翼…/尾羽_扇/腿趾爪/头顶冠羽` | 角色根 + Head/Body + 各部位（待其 README 细化） |
| 脚本 | `scripts/3d/`（多文件工具链：build / render_preview / check_render / inspect / feathers / utils + `_env.sh`） | `scripts/build_xiaoying.py`（单文件、相对自包含） |
| 参考配色 | 白大头、深色圆眼、黄喙、棕羽身、黄爪 | 头 `#FCF5EC` / 身 `#6B4A2D` / 翅 `#4E341E` / 喙爪 `#F9B32C` / 眼 `#120A04` |

## 一句话结论 / 选择建议

- **要更「毛茸茸、适合近距离展示」的成品感** → 版本 B（高精绒羽版）：粒子毛发细节更足、带四相机、
  配色明确取样，工程更“交付级”。
- **要「展翅飞行、偏写实、且愿意继续精修」的骨架** → 版本 A（展翅写实版）：姿态明确、结构分件命名清晰、
  方便逐部位微调，但当前是盲渲未经精修，需再打磨。
- 两版都可用 Blender 打开后按 F12（渲染引擎切 Cycles）出图；若内存足够，版本 B 的粒子
  `rendered_child_count` 可加到 40–80 获得更密绒感（见其 README）。

> 当前两版各有侧重，没有哪一版在所有维度全胜；选定主打版本后，可直接在本目录对应子文件夹里继续迭代。
