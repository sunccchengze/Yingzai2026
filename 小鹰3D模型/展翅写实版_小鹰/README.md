# 小鹰 · 3D 模型 (XiaoYing 3D mascot)

依据 `public/images/小鹰/*.png`（正面/侧面/背面/飞行等）解析出的造型制作，
配色与姿态由你确认：
**白色大头 + 两只深色圆眼 + 黄色小喙 + 棕色羽毛身体与翅膀 + 黄色脚爪**；Q 版轮廓、偏写实的羽毛层次；**展翅（飞行）姿态**。

## 文件
- `小鹰_3D.blend` — 主交付模型（Blender 4.5，Cycles 场景已就绪：相机 + 灯光 + 台座）。
- `preview.png` — 在沙箱内用 Cycles 渲染的预览图（CPU，采样有限，仅作快速预览）。
- `../../scripts/3d/build_xiaoying.py` — 可复现的建模脚本。

## 在 Blender 中打开
用 Blender ≥ 4.x 打开 `小鹰_3D.blend`，直接按 F12（渲染）即可出图。
- 打开后可在左侧 Outliner 的 `小鹰` 集合里分别选中 **头部 / 脸 / 喙 / 体羽 / 翅膀 / 尾羽 / 腿爪 / 冠羽** 等对象微调。
- 材质均用 Principled BSDF（含次表面散射、绒毛感 Sheen），若要更高精度可增加 `Cycles → Samples`。

## 模型结构（对象命名）
- `头_大圆脸` 白色大头
- `眼睛` + `眼_高光` 深色圆眼带高光
- `喙_上 / 喙_下 / 嘴角_开口`
- `身体_躯干` 与 `体羽_背侧 / 体羽_前胸`（大量重叠小羽片 → 毛茸茸层次）
- `翼/翼下/翼羽_飞羽/翼羽_覆羽`（左右展翅）
- `尾羽_扇`、`腿/趾/爪`、`头顶冠羽`

如需把当前（受沙箱 CPU 限制、由脚本盲渲、未经人工目视精修）的版本改成其他姿态、
放大头部、调整羽色/眼睛位置等，直接告诉我，我按参考图继续迭代。
