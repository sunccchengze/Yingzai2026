## 建模方法

**数据驱动，而非手调参数**：正面图逐行给 X 半宽、侧面图对应行给 Y 半深，
合成椭圆截面环沿 Z 放样。于是渲染出的正/侧剪影与参考图**天然对齐**。
三视图总高不同（610/600/614），行号按包围盒比例互相映射。

配色全部来自像素采样中位数：
白 `#FCF8F2` / 棕 `#6E4D2E` / 黄 `#F6B32A` / 口 `#E25C48` / 眼描边 `#281C0C`。

## ⚠️ 迭代踩坑记录（下一棒务必先读，避免重走）

1. **侧视图前胸是白色，不是棕色。**
   `build_body` 与 `Refs.cy_side` 最初都用 `brown` 掩膜取侧面深度/中心，
   而头部白羽垂下盖住前胸 → 躯干在 Y 向系统性后缩，Δ左端 98% 为正、均值 +25.6px。
   改用 `sil`（剪影）后 side IoU 0.839→0.860。**深度一律取剪影，颜色分界交给材质。**

2. **正面 y517 的 +82px 不是身体造成的。**
   连续三轮试 `taper_ends` 收尾系数、加大平滑窗口、自适应平滑，全部无效。
   核对采样才发现 body 在 y515 拿到 267px（参考剪影 279px）——身体是准的。
   真凶是**翅膀**：下缘锚在 y520，而参考图 y505..530 身体急剧收窄（348→259px），
   翅膀仍贴在体侧最宽处。锚点上提到 y500 后 → +82px 降到 +30px。
   **教训：偏差归因前先验证该部件的采样值，别急着调平滑。**

3. **`taper_ends(bot_frac=...)` 是端点补圈的缩放系数，不是收敛速度**，调它治不了腰身。

4. **IoU 对整体平移不敏感。**
   修正 `cy_side` 基准后 IoU 一点没变——因为所有部件都用 `r.Y()` 换算，
   基准平移会让模型整体移动，而 IoU 按包围盒归一化，平移被消掉。
   （该修正仍保留：它让世界坐标语义正确。）
   **想提分必须改「形状/比例」，不是位置。**

5. **收尾羽会反向拉低分数。** 第 8 轮把 `y_tip` 从 388 收到 376、喙尖抬到 248，
   side IoU 反跌 0.859→0.831，已回退。侧面偏宽 +4.5% 的账**不能记在尾羽头上**。

6. **参考图首末行是抗锯齿残留**（背面 y613 剪影仅 7px 宽），
   会让校准器报出 +230px 假警报。`calibrate.py` 已加边缘噪声剔除。
