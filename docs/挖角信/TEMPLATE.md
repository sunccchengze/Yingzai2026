# 宣传部「挖墙脚」信模板 v2（2026-09-09）

适用对象：报名表 `2026英仔爱心社报名表 的副本.xlsx` 中 #FABF8F（主题色 accent6 加亮 40%）标记的 16 人，第二志愿均为宣传部。

## 两条铁规

1. **无论给谁，衔接段必须落一句"我觉得我们很契合"**（可结合对方经历展开，但"契合"语义必须出现）。
2. **B/C 类正文零陕博痕迹**：不出现"陕博""陕历博"字样；陕历博考核句、名额过剩句仅 A 类使用。

## 通用主干（槽位：【姓名】【第一志愿】【姓】；成文时替换并删除括号）

【姓名】同学你好！！哈喽，我是宣传部的部长孙承泽，首先非常欢迎你选择来我们英仔的大家庭，我们非常欢迎、也非常期待你的到来！

单独来联系你呢，是因为我看到报名表上你的信息，你的第二志愿是宣传部，而且你感兴趣的方向、个人特长与优势我觉得相比【第一志愿】似乎更契合我们宣传部的工作耶！我个人也是对于摄影剪辑比较感兴趣，【衔接句：呼应对方 K/L/P 里最贴宣传的经历】自己大一也尝试做过播客，课程大作业上也尝试担任了一次编导，**我觉得我们很契合哎！**而且你应该也了解到现在的ai图片视频创作也是一直在蓬勃发展，我以及董懿部长在这个方面也是摸索了挺久、有不少体会，而且我们有一些私藏的创作类的新鲜工具可以与你一同分享，很希望你这种宣传型人才能加入宣传部一起和我们成长进步呀！

虽然的的确确是在挖墙脚......但我有两点我觉得你可以了解一下~

1.宣传部是职能部门，进入部门后可以自由旁听其余所有项目部门中的一个，也就是说，你可以在来到宣传后选择旁听【第一志愿】，【第 1 点尾部按变体】旁听干事和正式干事一起做志愿活动、一起团建，完全不会有隔阂，甚至有不少今年的部长都是因为太喜欢上一年自己旁听的部门，而去竞选旁听部门的部长成功的。旁听干事来竞选新任部长，也不会基本不会有任何阻碍。你要是真心喜欢【第一志愿】，我们部门以及整个社团不会对你有任何的限制，你可以直接加入【第一志愿】，也可以选择先来我们这里继续发展你的特长，同时不缺席【第一志愿】任何美好的瞬间。

而且我想澄清一下，旁听制度看起来好像要打两份工，但真的不会对你造成什么负担。我大一就在宣传，旁听手拉手的启梦，我感觉真的非常非常开心，旁听的项目部和宣传部都让我收获了很多珍贵的友谊和快乐，甚至参与团建的机会都×2哦~

2.【第 2 点按变体】

我说心里话，我感觉相比于【第一志愿】，你其实很适合很适合宣传部！你如果愿意，可以跟我说一下你是啥时间段面试，我只要有时间都可以去你的面试现场和你线下交流。

但总而言之，无论你去哪个部门，我们都很期待你在英仔拥抱快乐、收获成长，同时也更希望你能在宣传部绽放更明媚的光彩！

那我最后再多说一句嗷：

"小【姓】同学，来宣传部吧！我们在这里等你！"
