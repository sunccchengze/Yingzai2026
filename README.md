### 社团定位（年度总结原文）

> 西安交通大学英仔爱心社是由学生自愿发起并组成的**非营利性公益团体**，于 2010 年 10 月成立，同年 12 月正式挂牌。社团以「服务社会、奉献爱心、推己及人、薪火相传」为宗旨，通过大手拉小手支教、陕西历史博物馆志愿服务、碑林区敬老活动、物资漂流、特殊儿童陪伴等多种形式，提升大学生的社会责任感与奉献精神，在校园及社会中引领公益风尚，推动爱心火种不断传递。目前社团共有成员 199 人，定位为**开放型公益平台**，致力于搭建社会服务与爱心奉献之间的桥梁。

**长期主义的三条锚线**：玉树支教已走到**第十七届**；「知行秦川」由启梦（周至九峰）与拾辉（咸阳彬州）**双线并行**；**2015 年 12 月 13 日社友会正式挂牌**，让历届骨干的公益记忆不断代。历年故事曾被《人民日报》《光明日报》《陕西日报》等关注，本学年公众号文章亦获交大新闻网、交大团委等校内外媒体报道。

**经费来源**：唐仲英基金会（本年度报销 ￥11,912.84）。每学期由社团将所需报销项目报指导老师，由指导老师发起申请。社团为**非营利性组织，不向社员收取任何费用**。

## 2. 组织架构

英仔爱心社采用**以项目制为主、企业体制为辅**的管理体制，运行机制参照公司垂直管理模式，在社团理念、标准规划与人才选拔培养上均沿用此架构。

<div align="center">

<img src="public/images/架构图/治理架构图.png" alt="英仔爱心社治理架构：仲英书院指导，社长团为决策核心，团支部与社友会协同，下辖 3 个职能部门与 8 个项目部门" width="480">

</div>

| 机构 | 职能 |
|------|------|
| **社长团** | 日常运作核心。负责重大活动策划与监督、重大政策起草与修改、各部门协调管理、部长任免，以及暑期社会实践的组织领导。 |
| **团支部** | 由前任社长团成员及所有现任成员组成。监督社团发展与规章制度执行、参与全社成员培训、监督管理活动资料、开展内部思想文化建设。 |
| **社友会** | 2015 年 12 月 13 日挂牌。汇集历届核心骨干、正式社员与参与过活动的志愿者，展示社团发展历程、组建战略智囊团、搭建代际传承桥梁、承载社团文化与历史记忆。 |
| **职能部门** | 常务部、交流部、宣传部——负责社团内务、文化建设与对外宣传。 |
| **项目部门** | 8 个部门各自对接具体服务对象与合作机构，负责志愿者招募、培训、组织与考核。 |

**成长路径**：干事 → 部长 → 副社 → 社长团。每年招新录取的新成员均以**干事**身份进入部门。

## 3. 我们在做什么：11 个部门

> **找到属于你的「欢乐小屋」**
>
> 职能部门守护着日常运转，项目部门则把善意落在具体的人与事上。
> 在这里，你会遇到很多和你一样，愿意为一件小事认真花时间的人。一起备课，一起走进社区和场馆，也一起在活动结束后慢慢复盘。英仔一直在走的公益之路并不总是轰轰烈烈，但一代又一代英仔们愿意接续做下去，我们的事业就越来越有意义。

选部逻辑：**先选你想服务的人，再选你想练的本事。**

> **两条品牌线名词解释（新生最常问）**
> - **大手拉小手** = 助学线 → 启梦（九峰）+ 拾辉（文姬 / 彬州 / 大学游）
> - **青春伴夕阳** = 敬老线 → 向日葵（社区 / 老年大学）+ 常青藤（护理院）

> **旁听制度**：常务部、交流部、宣传部录取的新干事，可在首次破冰例会上选择一个旁听部门——职能部门干事可以任选一个项目部门旁听（启梦、拾辉、向日葵、常青藤、萤火、启明星、心项目、陕博部八个项目部门全部开放）。旁听主要听从个人意愿，实在冲突时由部长协调确定。旁听干事在活动与材料任务上基本与该部门干事同等参与，正式归属仍在本人录取的职能部门。
> 真实案例：有同学 2025 年作为宣传部干事旁听启梦，2026 年竞选为宣传部部长后，与启梦其他干事一同参加了九峰知行秦川支教。

### 逐项详述

**梦绽格桑原 · 玉树支教团（第十七届）**
7 月，支教团再赴青海称多县文乐中心寄宿学校。20 名志愿者为 230+ 名同学带来美育、音乐、舞蹈、体育、健康自护、科学等课程。破冰时藏语问候、心愿卡、汉藏互歌在现场回荡。**自 2010 年起，十七年接力从未中断**——去年的 25 名志愿者陪伴了约 700 名小学生。辞别大会「别时皆暖意」上，从舞蹈《爱你》、独唱《山茶花下》到合唱《等你下课》《送别》与《再见》，师生面对面诉说寄语。离陕后那一声声跨越群山的电话与好友申请，让这趟双向奔赴长久留存。

**大手拉小手 · 知行秦川，梦启今夏**
启梦部 11 名志愿者在周至县九峰初级中学陪伴 45 名营员，秦腔脸谱、机械艺术等趣味美育课程与破冰会、游园会、告别会依次展开。拾辉部 6 名志愿者走进彬州市中学，面向约 60 名高中生分享家乡、高三心路、专业与普法。收官课「我眼中的交大」与西迁精神，把视野留在孩子们心里。**我们知行秦川，让千百梦想，启于今夏。**

**萤火微光，向阳而生**
在西北妇女儿童医院「梦想小剧场」，志愿者用画笔与剪纸陪伴患儿，把床头化作画板，用游戏缓解医疗恐惧。千千爱特教中心完成多日陪伴，与孩子一起参与特奥融合赛。社区与阳光社工开展情绪识别小组。微光散在病房、特教与社区，却同属一个名字。

**启明寻洛，脉续中原**
从洛阳明堂、九洲池、龙门石窟、二里头，到开封宋代文旅。他们在遗址与街巷观察文化遗产保护，把好奇变为真实记录。洛阳博物馆与二里头，让河洛文明展开；开封文旅活化中，传统文化传播成为可触摸视角。那些脚步，终将写成可分享的故事。

**踏峪寻青，青护秦岭**
子午峪里他们徒步净山，向游客宣讲生态保护。自然博物馆与野生动物园研学，记录山林生灵故事。朱家湾山村访谈中聆听生态托起乡村振兴。把见闻带回社区，化作「秦岭青苗计划」三天课堂。净山、研学、问村让故事延续，校内回收漂流延续可持续行动。

**银发融城，心系长者**
20 名队员采取「统一调研体系、分散返乡执行」模式，携标准化问卷回到全国各自家乡，深入社区与街巷走访迁居老人，收回 200 份有效样本。聚焦老漂族在数字鸿沟、异地医保、社交孤岛与居住出行里的真实困难，也记录下广场舞队、邻里「老带新」的互助微光。成果正转化为智能手机教学、就医帮扶与独居走访。

**陕历博实践行**
2026 年 8 月起，陕历博暑假联队在陕西历史博物馆开展「传承中华文脉」主题社会实践。队员分为咨询接待、展厅保障两组，同时主动钻研馆藏史料、打磨讲解话术，在与不同年龄游客的交流中介绍展馆与重点展品。

## 11. 设计系统

### 设计立意

面向刚军训完的交大新生，做**真实、克制、有温度**的单页招新落地页。核心约束有三条：
1. **不写刷分话术** —— 五星级与志愿工时自然露出，不当卖点吆喝；
2. **不说 AI 空话** —— 严禁「赋能 / 旨在 / 共筑 / 无与伦比」一类套话，语态是学长平视交谈；
3. **不让新生思考** —— 三次点击内完成报名闭环。

### 色彩：莫兰迪红 + 玫瑰金

全部 token 定义在 `src/index.css` 的 `@theme` 块（Tailwind v4 CSS-first 配置）：

| 角色 | Token | 色值 |
|------|-------|------|
| 主色 · 工科红 | `--color-rouge-deep` | `#8E3F3D` |
| 主色 | `--color-rouge` | `#B25A55` |
| 主色柔和 | `--color-rouge-soft` | `#C97D74` |
| 主色雾感 | `--color-rouge-mist` | `#E2BDB6` |
| 辅助 · 玫瑰 | `--color-rose` / `--color-rose-soft` | `#D4A5A5` / `#E6C9C2` |
| 辅助 · 暖金 | `--color-gold` / `--color-gold-soft` | `#8A6A2E` / `#C9A876` |
| 文字 | `--color-ink` / `--color-muted` | `#3E3E3E` / `#5A5A5A` |
| 衬底 | `--color-cream` / `--color-paper` | `#FAF6F3` / `#FFFFFF` |

### 字体

| 用途 | 字体栈 |
|------|--------|
| 正文 `--font-sans` | DengXian / 等线 → Inter → Noto Sans SC |
| 中文标题 `--font-serif-cn` | Noto Serif SC → Songti SC → 等线 |
| 数字 `--font-data` | Libre Baskerville → Playfair Display → Georgia |

### 视觉语言

- **毛玻璃卡片 + 渐变描边**，1px 发丝边界，section 蒙版统一暖色调
- **Ken Burns 呼吸变焦**：首页 17 张轮播 `1.05x → 1.00x` 缓慢推近，视线锁在笑容与眼神
- **`layoutId` 共享元素转场**：部门小卡 → 全屏剧场视图无折损跃迁（framer-motion）
- **Lenis 平滑滚动** + 顶部 spring 阅读进度条
- **荣誉关键词 Marquee** 横向漫游，打断「全页都是三列卡」的节奏
- **小鹰吉祥物** 9 种姿态（正面 / 侧面 / 背面 / 挥手 / 爱心 / 报名 / 画画 / 飞行 / 相机），角落跟随
- **图标一律 Lucide**，禁用 emoji 当图标；hover 过渡 150–300ms

### 无障碍与容错

- 触控热区 ≥ 44px；全局 `focus-ring`；skip link
- 全站尊重 `prefers-reduced-motion`（marquee / 变焦 / 视差自动降级）
- 日光下高对比可读，muted 色刻意加深
- **视频四级回退**：B 站嵌入 → Cloudflare Pages 本站 mp4 → GitHub Release 原片 → 加速镜像
- **图片缺失自动跳过**：图集里未上传的编号不会留空位
- **QQ 群号占位保护**：若 `QQ_招新群号` 仍是 `123456789`，UI 自动改显「以招新现场与公众号为准」
- 荣誉视频 `onError` 自动回落 poster 图

## 13. 技术架构

```
React 19.2 · TypeScript 5.9 · Vite 7.3 · Tailwind CSS v4.1
├── framer-motion 12    共享元素转场、滚动动画

├── react-intersection-observer  进场触发与 nav 高亮
└── vite-plugin-singlefile       构建为内联单文件
```

```
Yingzai2026/
├── index.html                 入口（含 SEO / OG / JSON-LD）
├── vite.config.ts             singlefile · @ 别名 · host 0.0.0.0
├── src/
│   ├── App.tsx                页面组装 + Suspense 懒加载分片
│   ├── config.ts              ★ 单一数据源：链接 / 图片路径 / 二维码 / 视频源
│   ├── content.ts             ★ 全站文案与结构化内容（872 行）
│   ├── index.css              设计 token（@theme）+ 工具类
│   ├── components/            34 个组件
│   └── utils/
├── public/
│   ├── images/                品牌 / 首页 / 部门 / 荣誉 / 暑期实践 / 小鹰 / 公益剪影
│   │   ├── 架构图/            组织架构图 PNG（由脚本生成）
│   │   └── 小鹰/部门徽章/     12 只部门主题小鹰（AI 生成，架构图素材）
│   └── videos/                summer/ 压缩成片（单文件 ≤ 25MiB）
├── scripts/
│   ├── validate-assets.mjs        校验 config 引用的素材是否都存在
│   ├── audit-public-surface.mjs   对外信息面审计
│   ├── build-org-chart.mjs        组织架构图生成器（npm run org-chart）
│   ├── org-chart-data.mjs         架构图数据源：44 人姓名 / 职务 / 关键词标签
│   ├── faststart-mp4.mjs          mp4 moov 前置，秒开
│   └── strip-pages-video-assets.mjs  构建后剔除超限视频
└── docs/                      50+ 篇工程与内容文档
```

**关键工程约定**

- **`config.ts` 是唯一数据源**：所有链接、图片路径、二维码、视频源集中于此，组件不硬编码路径。
- **`content.ts` 是唯一文案源**：改字只改这里，不动组件。
- **首屏零阻塞**：Hero 与首屏组件同步加载，其余 6 个重区块 `lazy` + `Suspense` 骨架屏。
- **LCP 预加载**：首图 preload，背景图懒加载。
